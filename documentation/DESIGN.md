# Горизонтальный popup: макет и состояния

Дизайн для [#16](https://github.com/0Carpediem0/online-teaching-assistant/issues/16), внедрение — [#17](https://github.com/0Carpediem0/online-teaching-assistant/issues/17). Новый макет выполнен в коде; [Figma первой итерации](https://www.figma.com/design/MpXXCTtNm3ftGmr1Kb2XXw?node-id=3-166) сохранена только как архив.

## Компоновка

Popup шириной 640 px, внутренние отступы 20 px, скругление 28 px. Слева — белая карточка состояния пары с рамкой, под ней две квадратные плитки и кнопка «Проверка связи». Справа — прокручиваемая область анализа и широкая кнопка открытия чата внизу. Шапки с названием и иконкой и футера «О данных занятия» нет. На узком экране колонки располагаются друг под другом, содержимое доступно прокруткой.

Светлый фон `#f6f8f4`, текст `#20342d`, зелёный акцент `#246a51`, граница `#e1e7e1`, белые карточки. Шрифт системный Segoe UI/system-ui. Карточка статуса со скруглением 24 px, плитки — 18 px. Цвета продолжают предыдущую итерацию.

Полная переписка не занимает область результатов анализа. Кнопка открывает существующее окно PiP или переводит в него фокус. Если PiP не поддерживается, кнопка «Показать чат здесь» открывает отдельный экран с рабочим списком сообщений и возвратом в настройки. Доступная история фильтруется тем же общим состоянием. Закрытие окна чата не завершает пару.

## Состояния элементов

| Элемент / состояние | Поведение |
| --- | --- |
| До пары | «Начать пару»; анализ недоступен без активной пары и очереди сообщений |
| Пара идёт | «Завершить пару»; сбор новых сообщений продолжается при переходе в диагностику |
| После пары | Сводки и сообщения сохраняются; «Начать новую пару» очищает данные предыдущей пары |
| Плитка выключена | Белый фон, обычная рамка, `role="switch"`, `aria-checked="false"` |
| Плитка включена | Зелёная рамка и светло-зелёный фон, `aria-checked="true"` |
| Клавиатура / фокус | Нативная кнопка: Enter/Space переключают; видимый контур фокуса |
| PiP недоступен | Плитка отключена через `disabled`; описание причины доступно через `aria-describedby`; чат доступен на запасном экране |
| Открытие окна | Плитка и кнопка открытия временно отключены; подпись «Открываем…» |
| Окно открыто | Кнопка «Перейти к чату» переводит фокус в существующее окно, не создаёт второе |
| История | Независимая плитка, показывает ранее доступные сообщения; они не увеличивают счётчик новых |
| Анализ: ожидание | Пустые списки с текстом «Результатов анализа пока нет»; без фиктивных вопросов |
| Анализ: очередь | Кнопка показывает количество ожидающих сообщений; автоматическая отправка сохранена из main |
| Анализ: загрузка | «Анализируем…», кнопка отключена; предыдущие результаты остаются видимыми |
| Анализ: результат | Краткие вопросы, число исходных сообщений, технические проблемы и пятиминутные интервалы из ответа/сводки контроллера |
| Анализ: ошибка | Причина в области статуса, данные сохраняются; повторный анализ доступен для активной пары |
| Чат недоступен / ошибка PiP | Закрываемое уведомление с подсказкой; опрос не открывает закрытую ошибку повторно |
| Нет подключения | Экран подключения из main и уведомление; основная панель скрыта, возможное восстановление проверяется опросом |
| Диагностика | Отдельный экран: микрофон, уровень сигнала, камера, тест динамиков и подробности; кнопка назад возвращает фокус |
| Диагностика: проверка / старый замер | Индикатор выполнения и запрет повторного запуска; устаревшие результаты остаются с пометкой, как в main |

## Реализация

`src/view.ts` отображает полученное состояние, не создаёт искусственные результаты. `src/popup.ts` передаёт команды `start`, `stop`, `history`, `pip`, `chat`, `analyze`, `check-devices`. `src/content.ts` сохраняет контроллер main, очередь анализа, диагностику и жизненный цикл PiP. `src/pip-view.ts` сохраняет рабочий список переписки. `preview/demo.ts` использует те же компоненты с демонстрационным контроллером; кнопки сценариев переключают состояния макета.

Сообщения и ответы выводятся через `textContent`. Повторный опрос не пересоздаёт неизменившиеся списки. Имена студентов не добавлены, время чата показывается только при наличии времени платформы. Проверки и оставшиеся ограничения описаны в [DESIGN-CHECK.md](DESIGN-CHECK.md).
