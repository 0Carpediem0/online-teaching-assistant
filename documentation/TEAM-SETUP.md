# Запуск расширения участником команды

## На своём компьютере

1. Установите Node.js 22 или новее, Chrome и Docker Desktop с Linux containers. Склонируйте репозиторий и в его корне выполните `npm ci`, затем `npm run build`.
2. Скопируйте `.env.backend.example` в `.env`. Укажите `DEEPSEEK_API_KEY`, полученный в кабинете DeepSeek, и уникальный `ANALYSIS_API_TOKEN` длиной не меньше 32 символов. Это два разных ключа. Если собственного ключа DeepSeek нет, запросите у ответственного отдельный ключ **через согласованный безопасный канал**; в Git, Issue и PR ключ не добавляйте. Файл `.env` игнорируется Git.
3. Выполните `docker compose -f compose.backend.yaml --env-file .env up -d --build`. Команда `docker compose -f compose.backend.yaml --env-file .env ps` должна показать `analysis-api` как `healthy`.
4. Откройте `chrome://extensions`, включите режим разработчика и загрузите распакованную папку `dist`. Если расширение уже было установлено, нажмите его кнопку обновления и обновите вкладку Телемоста.
5. На странице расширения нажмите **«Параметры расширений»**. Укажите адрес `http://127.0.0.1:8787` и значение `ANALYSIS_API_TOKEN`, затем сохраните и разрешите доступ Chrome к этому адресу. Ключ DeepSeek в расширение не вводится.
6. Откройте тестовую встречу Телемоста, начните занятие, отправьте учебный вопрос и нажмите **«Анализировать сейчас»**, когда рядом появится число больше нуля. Для проверки без браузера выполните `npm run quality:pilot`: это один платный запрос к модели на синтетических данных.

Остановка: `docker compose -f compose.backend.yaml --env-file .env down`. Веса Ollama и данные Docker при обычной остановке не удаляются.

## Подключение к общему backend

Для команды на разных компьютерах текущий `127.0.0.1:8787` не подходит: он доступен только на машине с Docker. Администратор должен разместить API на сервере с внутренним DNS-именем и HTTPS reverse proxy, открыть доступ команде через сеть организации или VPN и выдать им адрес и отдельные учётные данные. После этого участник команды устанавливает только расширение и указывает адрес HTTPS API в его параметрах. Подробности и список недостающих решений приведены в [инструкции развёртывания](BACKEND-DEPLOYMENT.md). До настройки общего сервера каждый запускает свой локальный экземпляр по инструкции выше.
