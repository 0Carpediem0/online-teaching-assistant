# Первая итерация дизайна

Задача: [#4 — начало дизайна основного расширения](https://github.com/0Carpediem0/online-teaching-assistant/issues/4). Макет и фронтенд продолжают существующий каркас Телемоста, а не создают отдельную платформу обучения. Источник требований — [паспорт](PROJECT-PASSPORT.md), ограничения данных — [схема данных](DATA-FLOW.md).

Редактируемый [макет в Figma](https://www.figma.com/design/MpXXCTtNm3ftGmr1Kb2XXw?node-id=3-166): до занятия, во время пары, после завершения и отдельное окно чата. Использованы компоненты кнопок и переключателей Simple Design System. В Figma шрифт Inter заменяет недоступный Segoe UI; в расширении остаётся системный шрифт. Макет Figma статический; поведение проверяется в локальном интерактивном просмотре.

## Основной сценарий

Преподаватель открывает popup, выбирает отдельное окно при необходимости и начинает пару. Во время объяснения читает доступные сообщения рядом с презентацией. После завершения может просмотреть сообщения текущей вкладки, но готового итогового отчёта пока нет.

В popup одно основное действие в каждом состоянии: «Начать занятие», «Завершить занятие» или «Начать новое занятие». Новая пара очищает сообщения — об этом прямо сказано после завершения. Окно поверх презентации и просмотр доступной истории работают независимо; закрытие окна не останавливает сбор.

## Экраны и состояния

| Состояние | Что видит преподаватель |
| --- | --- |
| До занятия | Объяснение пользы, кнопка начала, настройки окна и истории |
| Занятие идёт | Доступность чата, кнопка завершения, новые сообщения и их счётчик |
| Чат открывается / недоступен | Текстовое состояние и подсказка открыть чат вручную |
| Пустой чат | Понятное сообщение об отсутствии новых сообщений без фиктивной статистики |
| Занятие завершено | Сохранённые сообщения и предупреждение об очистке при новом старте |
| PiP не поддерживается | Недоступный переключатель с объяснением; popup остаётся рабочим |
| Ошибка открытия окна | Сообщение от существующего контроллера; настройку можно попробовать снова |
| Открыта другая вкладка | Отдельный экран подключения с инструкцией открыть Телемост |

## Визуальное решение

Светлый фон `#f6f8f4`, белые поверхности, основной текст `#20342d`, зелёный акцент `#246a51`. Зелёный выделяет основное действие и доступный чат; предупреждения сопровождаются текстом, а не только цветом. Системный шрифт Segoe UI не требует загрузки из сети. Popup шириной 384 px; компактные сообщения прокручиваются внутри списка. Отдельное окно показывает текст крупнее, чтобы его было проще читать рядом с материалом.

Нативные кнопки и переключатели доступны с клавиатуры, фокус виден. Сообщения выводятся через `textContent`, без исполнения разметки чата. Имена студентов намеренно не показываются: их надёжность ещё не подтверждена. Время показывается только при наличии времени платформы. История помечена отдельно и не выдаётся за новые сообщения занятия. Счётчик — число новых наблюдений, а не вопросов, участников или проблем.

## Что входит в реализацию

Обновлены popup и оформление чата PiP, сохранены команды существующего контроллера. При опросе состояния список popup не пересоздаётся, если содержимое не изменилось, чтобы не сбивать чтение. AI-группировка, уведомления о вопросах, отчёт и авторизация не реализованы и не изображаются рабочими.

`npm run preview:build` создаёт самостоятельный `dist-preview/index.html`. В нём используются настоящие компоненты расширения с демонстрационным состоянием; переключатели сценариев и форма тестового сообщения существуют только на странице просмотра. Окно PiP здесь показано во встроенной рамке: права браузера и работу настоящего Document PiP проверяют отдельно в установленном расширении.

## Ручная проверка

1. В макете пройти состояния до, во время и после пары, недоступный чат и браузер без PiP.
2. Начать и завершить занятие; убедиться, что новый старт очищает список.
3. Включить историю: появляется помеченная стартовая строка, счётчик новых наблюдений не растёт.
4. Изменить настройку окна; проверить независимость истории и окна.
5. Добавить длинное тестовое сообщение и текст с HTML-тегами: текст переносится, разметка не исполняется.
6. Пройти кнопки и переключатели клавишей Tab, активировать пробелом/Enter.
7. Проверить узкий экран 320 px и длинные сообщения без горизонтального переполнения.
8. После установки расширения проверить в тестовой встрече команды начала/завершения, реальный PiP и повторное открытие popup. Демо не заменяет эту интеграционную проверку.

### Выполненная проверка этой итерации

Проверка TypeScript прошла. Расширение и самостоятельный HTML собраны; из-за ограничений чтения каталогов нативным esbuild в рабочей среде использован `esbuild-wasm` той же версии 0.27.7 через существующий параметр сборочного скрипта. `esbuild-wasm` не добавлен в зависимости проекта. Обычная сборка нативным esbuild в этой среде не подтверждена.

В отдельном DOM-стенде проверены состояния занятия, вызовы команд, независимость переключателей, фильтрация истории, счётчик, ошибки, отсутствие исполнения HTML из сообщения, сохранение узлов при повторном опросе, ограничение в 100 строк, обновление текста в PiP и запуск собранного самостоятельного макета. Это проверка логики без браузерного расчёта размеров.

Макет Figma проверен изображением и структурой: редактируемый текст и компоненты, без растровой копии интерфейса. Автоматическое открытие локального превью во встроенном браузере завершилось ошибкой, поэтому проверка реальной вёрстки на ширине 320 px, клавиатурной навигации в браузере, установленного расширения и встречи Телемоста остаётся ручным шагом.
